# titanic-decision-tree

Проект по предсказанию выживаемости пассажиров Титаника с использованием деревьев решений и сравнением с другими моделями классификации.

## Описание
Проведён разведочный анализ данных, обучена модель дерева решений, подобраны гиперпараметры, выполнено сравнение с Random Forest и Logistic Regression. Оценены точность, ROC-AUC, важность признаков и кривые обучения.

## Структура репозитория
`01_EDA.ipynb` — загрузка данных, анализ пропусков, визуализация зависимости выживаемости от пола, класса, возраста, корреляционная матрица.
`02_Decision_Tree_Model.ipynb` — предобработка данных, обучение базового дерева, визуализация дерева, подбор гиперпараметров через GridSearchCV, оценка качества, матрица ошибок, важность признаков.
`03_Model_Comparison.ipynb` — сравнение Decision Tree, Random Forest и Logistic Regression, ROC-кривые, матрицы ошибок, кривые обучения.

## Используемые технологии
- Python 3
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn

## Как запустить
1. Клонировать репозиторий.
2. Открыть нужный ноутбук в Jupyter Notebook или Google Colab.
3. Запустить все ячейки последовательно (данные загружаются автоматически).

## Результаты
- Базовая модель дерева решений переобучается, точность на тесте ниже, чем на трейне.
- После подбора гиперпараметров точность на тесте улучшилась.
- Random Forest и Logistic Regression показали более высокие результаты, чем одно дерево.
- Наиболее важные признаки: пол, класс билета, возраст, тариф.

## Выводы
Дерево решений — интерпретируемая модель, склонна к переобучению. Ограничение глубины и настройка параметров помогают улучшить обобщающую способность. Ансамблевые методы (Random Forest) дают более стабильные и точные предсказания для задачи выживаемости на Титанике.
